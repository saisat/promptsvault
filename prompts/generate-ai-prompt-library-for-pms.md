## prompt

```
Role:
Act as a Prompt Engineer, an Expert Product Manager, and a Strategic Operator.

Task:
I will give you a product management Work Area (for example: Market Analysis, Customer Discovery, Experimentation).
Create a Prompt Library that an elite product manager in that field designed.

Output format:
Write the deliverable in Markdown. Use these four parts:

1. Title: “<PM Work Area> — AI Prompt Library for Product Managers”

2. Summary (maximum 100 words): Explain how top product managers in this work area think, what drives results, and how they scale their work.

3. Popular Approaches: List 5–10 key strategies, frameworks, or operating principles that elite product managers use in this field. For each one, include:
   - A name (for example: "Problem-Solution Fit")
   - A 1-line description
   - A practical, bite-sized lesson
   - A source or citation (Operator + Year, or company if applicable)

4. Actionable AI Prompts: Write exactly 10 actionable prompts. For each prompt, include:
   <Goal>
   Why this fits: (maximum 50 words) Explain why this prompt reflects cutting-edge thinking in this area.
   How you would use it: Explain how the product manager deploys the prompt in a real-world workflow. Include the tool or channel if relevant.
   Starter Prompt: Write the prompt text in the voice of an advanced operator. Write it specifically with the <prompt-elements> below. Write the Starter Prompt in Markdown.

Style:
- Use clear, modern product management language.
- Prioritize tactics that *scale*, not fluff.
- Be concise, punchy, and operator-grade.

Sources:
Use examples, operators, or results from trusted sources after 2015 (for example: Reforge, Lenny Rachitsky, Institute of Product Leadership blogs, Product School).
DO NOT include any references in the output.

<prompt-elements>)



Style: 

• Use clear, modern product management language. 

• Prioritize tactics that *scale*, not fluff. 

• Be concise, punchy, operator-grade. 

* The Starter Prompt MUST be in Markdown format



Sources: 

Use examples, operators, or results from trusted sources post-2015 (e.g. Reforge, Lenny Rachitsky, Institute of Product Leadership blogs, Product School etc). DONOT include any references in the output.



<prompt-elements>

#### CONTEXT & OBJECTIVE ####

The current context, outcome or goal that outlines the situation for which the prompt is needed. It helps the LLM understand what knowledge and expertise it should reference when creating the prompt.

#### STYLE #### 

Defines the role, skill level and expertise of the operator

#### TONE #### 

The attitude / voice / tone of the response generated by the LLM to ensure it  resonates with the intended sentiment or emotional context required.

#### AUDIENCE ####

The ultimate consumer of the output that the prompt creates. 

#### RESPONSE #### 

The structural arrangement or response format style of the LLM's generated content. It determines how information is organized, displayed, or encoded to meet specific user preferences or requirements. 

#### STEPS #### 

The action and step-by-step instructions that the prompt will ask the LLM to take. It should be a numbered list of sequential steps that will make the most sense for an LLM to follow in order to maximize success.

</prompt-elements>
```

## when-to-use

Create a scalable, operator-grade prompt library for any specified product management work area. It emphasizes elite PM frameworks, tactical lessons, and ten structured “starter prompts” using defined context/style/tone/audience/response/steps elements. Output a titled Markdown library with a brief summary, popular approaches, and exactly 10 actionable prompts.

## notes

> [!info] How to use
> Paste the prompt, then send a product management Work Area (for example: Market Analysis) as your next message. The model fills `<PM Work Area>` and `<Goal>` itself, and `<prompt-elements>` is a block of definitions inside the prompt.

> [!warning] Possible contradiction
> Item 3 asks for “a source or citation” for each approach, but the Sources section says “DONOT include any references in the output.” The source note does not say which one wins.
