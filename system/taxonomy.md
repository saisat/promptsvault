# Taxonomy

Draft category list. Edit freely; skills read this file and refuse to invent categories outside it.

| category | use for |
|---|---|
| product-management | PM strategy, discovery, roadmaps, dilemmas, case studies |
| market-research | market, competitor, and business-model analysis |
| writing | drafting, editing, and style work |
| web-elementor | site layout, design tokens, and Elementor/page-structure pipelines |
| education-research | course, degree, and entrance-exam research |
| meta-prompting | prompts that write, improve, or generate other prompts |
| thinking-partner | critique, mentoring, and stress-testing of ideas |

## Tag conventions
- kebab-case, singular where natural (`critique`, not `critiques`).
- Tags describe technique or topic (`chain-of-thought`, `yaml`), not the category.
- Prefer an existing tag over a new near-duplicate.
